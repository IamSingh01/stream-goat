> [!NOTE]
> **Updating from 10.0.0:** Android installs over 10.0.0 from inside the app (Settings → Updates and backup), no
> uninstalling. Windows, Mac and Linux: install this version over the old one once; from now on small updates install
> from inside the app.

## What's new in 10.0.1

**A new player on Windows, Mac and Linux: mpv**

- **mpv** (FFmpeg inside) is now the main player. Like ExoPlayer on Android, it reads streams itself: **NetMirror plays**
  with its real length (not 27:46:39), seeks where you ask, and its audio languages (English, Hindi, Tamil…) are in the
  Audio menu. VLC stays as the backup: if one can't play a source, the other is tried. Settings → Player → "Which
  player plays a video", or switch while watching (Sources menu).
- The Stream Goat (JavaFX) player from the test builds is gone.

**Small updates inside the app**

- **Windows, Mac and Linux:** Settings → Updates installs a small update (about 15 MB instead of the whole installer)
  when only Stream Goat's own code changed, then restarts. Updates are signed; one that doesn't start is dropped and the
  installed version opens. A **Test builds** switch gets the newest test versions.
- **Android:** updates download only what changed (a few MB instead of 65 MB) and are checked before installing; if
  anything is off, the whole APK downloads as before.

**Fixes**

- Phones: the **Settings** button was pushed off the bottom bar (with Sports, Music and YouTube added); it's always
  there now, and the tabs scroll on narrow phones.
- Streams with brackets in subtitle addresses (NetMirror) and segments disguised as pictures play through the app's
  proxy; encrypted (AES-128) streams too.
- Fire TV, Google TV and TV boxes: install with the Downloader app and the code **4564305**.
- Linux (.deb): installs libmpv with the app. The Flatpak plays with VLC.
